# Student Grade Tracker

## Description

Student Grade Tracker is a Java application that helps manage student grades. It allows users to enter student information, calculate average scores, and find the highest and lowest grades.

## Features

* Add student names and grades
* Store data using ArrayList
* Calculate average score
* Find highest score
* Find lowest score
* Generate a summary report

## Technologies Used

* Java
* ArrayList
## How to Run

1. Compile the program:
   javac StudentGradeTracker.java

2. Run the program:
   java StudentGradeTracker

## Project Structure

* StudentGradeTracker.java : Main source code
* screenshots/ : Output screenshots
* README.md : Project documentation

## Output

Program displays:

* Student details
* Average score
* Highest score
* Lowest score
